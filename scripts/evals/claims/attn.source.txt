Transformer Network
Vaswani et al. (2017)
1
A sequence-to-sequence model that uses only attention and
feed-forward layers
Encoder: multi-head self attention
I
The query is a specific word in the input

The keys and values are the other words in the input
Note that none of theq,k, andvdepend on each other

Unlike with an RNN encoder-decoder, where theqis the
decoder state, which depends on the previous decoder state

So with a transformer, we can do the attention calculations in
parallel for efficiency

Transformer Network
Encoder
1. Compute multi-head self attention for each input word
2. Normalize the resulting outputs

4. Now we have a new sequence of multi-head attention outputs
5. Compute multi-head self attention over the new sequence

27/31

Transformer Network
Decoder
1. Compute the decoder states using multi-headselfattention
over predicted words so far
2. Compute multi-headnormalattention between the decoder
states (query) and the encoder states (key/value)
3. Run the output through a feed forward layer to produce a new
set of decoder states
4. Repeat for a total of 6 runs
5. Run the final output through a feed forward layer with
softmax activation to predict the next word
6. Repeat until the</s>token is predicted or the maximum
prediction length is reached

29/31

Transformer Network
The transformer gives very good performance
I
It beats both phrase-based and RNN machine translation
I
It also performs comparably with state-of-the-art RNN
constituency parsers
It is theoretically efficient to train due to parallel computation
I
However in practice, we still need very large models to get
good performance
I
Its autoregressive decoding is slower than RNN decoding (and
can’t be parallelized)
I
It is also more sensitive to hyperparameter tuning than RNN
